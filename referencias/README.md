# Referencias

Documentos oficiales del Hackathon INE 2026, para consulta.

- convocatoria.pdf: las bases oficiales del concurso.
- rubrica-evaluacion.pdf: la rúbrica con la que califican (100 puntos).
- aviso-privacidad-integral.pdf y aviso-privacidad-simplificado.pdf: cómo trata el INE los datos personales.
- carta-cesion-de-derechos.pdf y carta-declaratoria-decir-verdad.pdf: los formatos en blanco. Las cartas firmadas se entregan en el .zip y no se suben aquí, porque llevan firmas personales.

Estos archivos son del INE y están aquí solo como referencia.
